# Пояснительная записка по сайту TastyAI

## Реализованный функционал

1. **Авторизация и регистрация**
   - Пользователь может создать аккаунт (имя, пароль) и войти в систему.
   - Сессия хранится в cookie (`session_token`), таблица `authentications`.
   - Пароли хешируются.

2. **Просмотр доступных тестов**
   - Страница `tests.html` загружает список всех не приватных тестов через API `/api/get_tests`.
   - Реализован поиск по названию, описанию и направлению.
   - Пагинация (кнопка «Ещё»).

3. **Прохождение теста**
   - Страница `test_solution.html` получает данные теста (вопросы без правильных ответов) и начинает попытку (`attempt`).
   - Интерфейс с пошаговым переключением вопросов, прогресс‑баром.
   - Поддерживаются типы вопросов: выбор одного ответа (choice), выбор нескольких (many_choice), текстовый ввод (text).
   - После завершения теста ответы отправляются на `/api/solve_test`.

4. **Проверка ответов (два режима)**
   - **Режим «key»** — строгое сравнение с эталоном (с учётом регистра/пробелов, для множественного выбора — полное совпадение).
   - **Режим «ai»** — ответы и тест отправляются в DeepSeek API, который возвращает для каждого вопроса флаг `is_correct` и пояснение, а также итоговый вердикт.
   - Результат сохраняется в таблице `attempts` (поле `answers` — JSON, поле `verdict` — текст).

5. **Создание теста**
   - Страница `create_test.html` с пошаговым мастером.
   - Настройки: название, описание, категория, выбор режима проверки (ключи / ИИ).
   - Динамическое добавление/удаление вопросов, выбор типа вопроса (choice / many_choice / text).
   - Формирование JSON и отправка на `/api/save_test`.
   - Тест сохраняется в БД, привязывается к автору (если пользователь авторизован).

6. **Главная страница**
   - Краткое описание сервиса, призыв к действию, ссылки на создание теста и готовые тесты.
   - Адаптивный дизайн, анимации.

## Краткий вывод

Проект представляет собой рабочий движок для создания и прохождения тестов с возможностью использования ИИ для проверки ответов. Реализована полноценная серверная часть на Flask, клиентская часть на чистом JavaScript, база данных SQLite. Интерфейс интуитивно понятен и адаптивен. Основные нереализованные функции касаются персонального кабинета автора тестов (список своих тестов и статистика по ним), а также редактирования/удаления. Дальнейшая разработка должна быть направлена на завершение этих модулей и улучшение безопасности.
